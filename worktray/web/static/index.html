About worktray


worktray pulls your meetings, pull requests, tickets and follow-ups into one list, and shows whose move each one is.


What you can do


    

  • See everything that needs you in one table, with work that's waiting on someone else kept apart.
    • 

  • Star what's next, snooze what can wait until this afternoon, tomorrow or after your next meeting, and dismiss the rest.
    • 

  • Catch asks from Slack and action items from meeting notes. When one mentions your ticket or pull request, it shows up on that row.
    • 

  • Close asks faster: when the ticket or pull request behind an ask is done, worktray offers to close it.

Your data


Everything stays on this computer. worktray keeps titles and links in a small database in your user data folder, or wherever WORKTRAY_HOME points. It reads messages and notes to find your tasks, then throws the text away. Tokens live in your system keychain, and your sources are only ever read, never changed.


The Slack and tidy-up features send item titles and links to the Codex agent you set up, and any coding agent you connect over MCP can read your list.


Agent work


Coding agents can add tasks and mark them done with a result. Sessions worktray finds on its own arrive as suggestions, because a chat ending doesn't mean the work is done.


Running in the background


worktray only listens on this computer. Run worktray service install to start it when you log in.
